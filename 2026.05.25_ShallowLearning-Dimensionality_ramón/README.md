The input CSV is **not** included in this bundle (too large, gitignored). It is generated by
`Final-Search-ML-Pipeline/run_pipeline.py` and lives at
`Final-Search-ML-Pipeline/csv/all_cities_combined.csv`.

To regenerate it:
```bash
cd Final-Search-ML-Pipeline
python run_pipeline.py              # all 6 cities
python run_pipeline.py NYC Chicago  # specific cities
```

First run takes ~15 min (Overpass queries + cache); subsequent runs ~2–3 min.

## How to run

1. Open **`config.py`** and tweak the parameters at the top
2. Open either notebook in VS Code or Jupyter
3. Restart Kernel + Run All

Both notebooks read the same `config.py`, so a single change propagates everywhere.

## Parameters (`config.py`)

| Parameter | Default | Options |
|---|---|---|
| `SOURCE` | `'osm'` | `'property'`, `'osm'`, `'mixed'` |
| `CITIES` | `None` | list or None |
| `CITY_GROUP` | `None` | `'ground_truth'`, `'osm_only'`, `None` |
| `BALANCE_METHOD` | `'undersample'` | `'undersample'`, `'none'` |
| `FEATURES` | `None` | explicit list or None (overrides SOURCE) |
| `EXCLUDE_FEATURES` | `[]` | list |
| `RANDOM_STATE` | `42` | any int |
| `TEST_SIZE` | `0.2` | float in [0,1] |

`SOURCE` controls which features (and indirectly which cities) are used:

- **`'property'`** — 5 features from official property datasets (PLUTO/OPA/Cook County). Forces ground-truth cities (NYC, Philadelphia, Chicago).
- **`'osm'`** — 9 features from OpenStreetMap. Works for any city.
- **`'mixed'`** — 14 combined features. Forces ground-truth cities. Also exports two separate CSVs.
